## Carewell Health Care

Carewell Health Care is a Flutter-based e-commerce mobile application that allows users to browse and purchase healthcare and personal care products through a clean and modern interface. It was developed as part of the SWE311 – Mobile Application System Design course.

## Features

- Onboarding screens to introduce the app’s purpose and main functions  
- User authentication (email & password login screen)  
- Home screen with search, popular categories, promotions, and popular products  
- Product details page with images, price, description, rating, and reviews  
- Shopping cart with quantity control and checkout flow  
- Checkout screen with order summary and payment success screen  
- Store screen with brands and category-based product browsing  
- Wishlist screen for saving favourite items  
- Profile screen with basic account information and settings

## Tech Stack

- Flutter  
- Dart  
- Android (tested on emulator/device)
